# 10/31 시연 스크립트

## 준비 (시연 전날)

1. 키 확인: `backend/.env`에 `CLAUDE_API_KEY`, `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`이 있는지 확인
2. 백엔드 실행: `cd backend && python3 -m uvicorn app.main:app --port 8000`
3. 프론트 실행: `cd frontend && npm run dev` → http://localhost:5173
4. 자동 검증 실행: `cd backend && RUN_LIVE=1 python3 -m pytest -m live -v -s` (실제 호출, 약 1분, 비용 약 $0.08)
5. 프론트 E2E: `cd frontend && npm run e2e`

## 시연 흐름 (약 5분)

1. **문제 제기 (30초)**: "애널리스트는 매일 아침 뉴스 10여 개를 2~3시간 동안 확인합니다."
2. **면책과 원칙 (30초)**: 화면 상단 "투자는 본인의 판단으로 하시기 바랍니다"와 신뢰성 규율 4개 카드를 보여줍니다.
3. **지금 생성 시연 (90초)**: "지금 생성하기"를 누릅니다. 단계 문구가 바뀌는 동안 설명합니다. 생성은 약 50~60초 걸립니다.
4. **요약 1~2개 읽고 원문 대조 (120초)**: 카드 하나를 골라 요약을 읽고 "원문 보기"를 눌러 원문과 비교합니다.
   - 확인할 것: 요약의 수치와 날짜가 원문에 있는지
   - 원문에 없는 내용이 없는지
5. **시장 전망과 투자포인트 (60초)**: 전망이 "~할 가능성이 있다"처럼 조건부로 쓰였음을 보여줍니다. 투자포인트는 권유가 아니라 관찰 지점입니다.
6. **위험도와 출처 (30초)**: 위험도 배지와 언론사, 날짜, 링크를 가리킵니다.
7. **이메일 (30초)**: 구독 폼에 입력하고 미리보기가 오늘 보고서 내용이라는 점을 보여줍니다. 실제 발송은 v2라고 분명히 말합니다.

## 신뢰성 설득 포인트

- 할루시네이션 금지: 요약은 기사 원문 정보만 씁니다. 자동 검사로 수치 근거를 확인하지 않는 부분은 사람이 원문과 대조합니다.
- 단정성 제어: 자동 검사로 "사세요", "반드시" 같은 권유 표현을 막고, 실패하면 재생성하거나 오류로 멈춥니다.
- 출처 명시: 모든 뉴스에 언론사, 발행일, 원문 링크가 있고, 자동 검사로 누락을 확인합니다.
- 편향성: 섹터 분포를 자동으로 점검하고, 한 섹터가 60%를 넘으면 경고합니다.
- 비용 추적: 요약과 전망마다 입력·출력 토큰을 로그로 남깁니다.

## 한계 (질문이 나오면 솔직하게 답할 것)

- 요약 입력은 기사 제목과 네이버 제공 요약문입니다. 기사 본문은 저장하지 않으므로, 정확성 검증은 원문과의 대조가 최종 기준입니다.
- 위험도는 모델이 스스로 평가한 값입니다.
- 비용 집계는 로그 기반입니다. 일일·월별 합계 화면은 아직 없습니다.
- 구독 발송은 v2입니다.
